# EdenRise 3D — LiDAR point cloud as 3D Tiles
DGT 2024 LiDAR (10 pts/m²) over the EdenRise estate, coloured from the 2025 25 cm orthophoto, thinned (ground 1/6, vegetation and buildings 1/2), converted with py3dtiles. Consumed by the 3D twin at edenangels.github.io/edenrise-map/3d.html. Regenerate: `scripts/lidar_3dtiles.py` then `py3dtiles convert` in edenrise-ops-gis.
